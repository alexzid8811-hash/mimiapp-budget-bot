# Ручная установка исправления утреннего отчёта

1. Распакуйте архив в корень проекта `/opt/budget-miniapp` с заменой файлов.
2. Проверьте синтаксис и пересоберите контейнеры:

```bash
cd /opt/budget-miniapp
python -m py_compile app/db.py app/morning_reports.py bot.py
docker compose up -d --build
docker compose logs --tail=50 bot
```

Исправление:

- выводит каждую операцию за вчера отдельной строкой;
- показывает фактическую сумму на карте на момент отправки;
- сравнивает дневную норму, а не остаток после расходов;
- добавляет недостающий столбец базы автоматически при запуске.
